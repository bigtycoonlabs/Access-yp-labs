Keys

Keys let Penny put what she builds onto your own GitHub, Railway and Supabase accounts. They are encrypted, never shown again once saved, and Penny uses them without ever seeing them. Never paste a key into a chat; if you do, Penny takes it out and brings it here.

On file

Add or replace a key

I check it with the service before saving, and tell you what it can reach. Adding a key replaces the one on file for that service.

Where do I get each key?

GitHub: Settings, Developer settings, Personal access tokens, Fine-grained tokens. Give it access to only the repositories Penny should use, with Contents read and write, and an expiry date.

Railway: Account settings, Tokens. An account or workspace token can create new projects; a project token can only deploy to one that exists.

Supabase: Account, Access Tokens. It starts with sbp_. A project's secret key is not the right one.

Replace every key at least every 90 days. Penny puts a reminder on Today.
