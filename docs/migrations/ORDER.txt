# Filename order does not work and never did. On a clean database, 46 of the 54 files fail and only
# five tables get created, because `users` — which nearly every other file references — is created in
# 050_recover_untracked_tables.sql, and 050 sorts near the end. The live database is fine only
# because it was built up over time rather than restored from these files; a genuine restore from
# version control would have produced a broken system, and nobody would have found out until they
# needed it.
#
# Renaming the files would break every reference to them in commits and notes, so the order lives
# here instead. scripts/migrate.sh reads this file. A test fails if a .sql file exists that is not
# listed here, so a new migration cannot be silently forgotten.
